# Global Flight Grid

An interactive 3D globe with glowing animated flight arcs between world cities, styled like a sci-fi data dashboard.

**Live:** https://edenlich.github.io/Agentic-prog-lab1/

Pure static HTML/CSS/JS. Three.js and the Natural Earth land outlines (world-atlas) load from the public jsDelivr CDN. No backend, no build step, no API keys. Open `index.html` directly in a browser to run it locally.
